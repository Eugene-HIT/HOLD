# 完整小 Demo 接线表

## 1. 目标模块范围

本接线表面向当前准备组装的完整小 Demo，纳入以下模块：

1. MPU6050 IMU
2. MAX30102 PPG
3. DRV2605L + LRA 震动模块
4. RGB 共阴极三色 LED
5. 薄膜压力传感器模块（AO / DO / VCC / GND）

本表不包含当前仓库里的 AD8232 ECG 和 ICS43434 麦克风，因为你这轮明确要先整合的是 IMU、PPG、震动、RGB、压力。

## 2. 先说结论

建议整机版采用如下总线与引脚策略：

1. IMU、PPG 共用主 I2C：
   - SDA: D4 / GPIO5
   - SCL: D5 / GPIO6
2. DRV2605L 单独使用副 I2C：
   - SDA: D6 / GPIO43
   - SCL: D7 / GPIO44
3. RGB 共阴极三色 LED 使用 3 个独立 GPIO：
   - R: D8 / GPIO7
   - G: D9 / GPIO8
   - B: D10 / GPIO9
4. 薄膜压力模块使用模拟输出 AO：
   - AO -> D0 / A0 / GPIO1
   - DO 本轮不接

这样接的理由是：

1. 现有各模块不存在 I2C 地址冲突，但 DRV2605L 作为震动驱动器，单独分总线更利于整机排障。
2. 压力模拟输入和 I2C / RGB 不冲突。
3. RGB 选用 D8-D10 后，不会占用当前主线已经确定的 I2C 和 ADC。
4. 不使用 GPIO0，避免碰启动绑带脚。
5. 不占用板载用户灯 GPIO21，避免和现有系统状态灯逻辑混淆。

## 3. 现有代码里的真实占用情况

### 3.1 主线/共享配置里的既有口径

根据 [include/project_config.h](include/project_config.h)：

1. 共享 I2C：
   - SDA = GPIO5
   - SCL = GPIO6
2. 压力模块模拟输入：
   - GPIO1
3. 板载用户灯：
   - GPIO21

### 3.2 独立实验环境里的特殊口径

当前仓库里有几个独立实验入口，为了单独验证模块，曾经故意用了不同接线：

1. IMU 呼吸实验 [src/mpu6050_xiao_esp32s3_respiration/main.cpp](src/mpu6050_xiao_esp32s3_respiration/main.cpp)
   - I2C: D4(GPIO5) / D5(GPIO6)

2. MAX30102 独立 VOFA 环境 [src/max30102_xiao_esp32s3_vofa/main.cpp](src/max30102_xiao_esp32s3_vofa/main.cpp)
   - I2C: D2(GPIO3) / D3(GPIO4)
   - 这是独立展示环境的临时口径，不是必须保留到整机版

3. DRV2605L 独立 LRA 环境 [src/drv2605l_xiao_esp32s3_lra_breath/main.cpp](src/drv2605l_xiao_esp32s3_lra_breath/main.cpp)
   - I2C: D6(GPIO43) / D7(GPIO44)
   - 这是为了在独立实验时完全避开 IMU / PPG 线路，不代表整机版必须单独占一组 I2C

## 4. 冲突判断与最终调整

### 4.1 IMU / PPG / DRV2605L 是否冲突

结论：

1. 引脚层面，如果保留各自独立实验口径，不冲突。
2. 总线层面，这三个模块理论上可以并到同一组 I2C 上。

原因：

1. MPU6050 常用地址为 `0x68` 或 `0x69`
2. MAX30102 地址为 `0x57`
3. DRV2605L 常用地址为 `0x5A`

但整机版这次不建议让三者都硬并到一组 I2C。原因不是地址冲突，也不是单纯带宽不够，而是：

1. DRV2605L 对应的是主动震动输出链路，本身更容易带来供电和机械扰动。
2. PPG 对微小扰动更敏感，IMU 又正好在量运动。
3. 把 DRV2605L 独立到副 I2C 后，后续整机联调时更容易区分是“总线问题”还是“振动耦合问题”。

因此本轮整机版最终建议是：

1. 主 I2C：IMU + PPG
2. 副 I2C：DRV2605L

主 I2C 接法：

1. SDA = D4 / GPIO5
2. SCL = D5 / GPIO6

副 I2C 接法：

1. SDA = D6 / GPIO43
2. SCL = D7 / GPIO44

### 4.2 压力模块是否冲突

结论：不冲突。

理由：

1. 当前工程已经把压力模块 AO 口定义在 D0/A0(GPIO1)。
2. 这个引脚不与 I2C、板载 LED、当前推荐 RGB 引脚重叠。
3. 模块的 DO 是比较器数字输出，本轮你要的是模拟压力数据，因此不需要接。

### 4.3 RGB 共阴极三色 LED 是否冲突

结论：建议使用 D8 / D9 / D10，不与本轮完整 Demo 目标模块冲突。

理由：

1. D8(GPIO7)、D9(GPIO8)、D10(GPIO9) 当前不被 IMU / PPG / DRV / 压力使用。
2. 这三个脚连续，布线和代码定义都更清晰。
3. 避开了 GPIO0 启动脚和 GPIO21 板载灯。

注意：

1. 如果你后面又想把 ICS43434 麦克风并进来，那么 D8-D10 会和麦克风 I2S 冲突。
2. 但按你本轮目标，麦克风不在整合范围内，所以当前这样分配最合适。

## 5. 推荐整机版接线总表

### 5.1 电源与地

所有模块必须共地。

建议：

1. XIAO 3V3 -> MPU6050 VCC
2. XIAO 3V3 -> MAX30102 VIN
3. XIAO 3V3 -> DRV2605L VIN
4. XIAO 3V3 -> 薄膜压力模块 VCC
5. XIAO GND -> MPU6050 GND
6. XIAO GND -> MAX30102 GND
7. XIAO GND -> DRV2605L GND
8. XIAO GND -> 薄膜压力模块 GND
9. XIAO GND -> RGB LED 共阴极公共脚

### 5.2 I2C 总线

主 I2C 接法：

1. XIAO D4(GPIO5) -> MPU6050 SDA
2. XIAO D4(GPIO5) -> MAX30102 SDA
3. XIAO D5(GPIO6) -> MPU6050 SCL
4. XIAO D5(GPIO6) -> MAX30102 SCL

说明：

1. 这是标准 I2C 并联接法，不是串联。
2. MPU6050 与 MAX30102 共享该总线。
3. 这两个都是传感器侧读数据链路，放在同一主 I2C 更合理。

### 5.3 MPU6050

建议接法：

1. 3V3 -> VCC
2. GND -> GND
3. D4(GPIO5) -> SDA
4. D5(GPIO6) -> SCL
5. AD0/ADO -> GND
6. INT/XDA/XCL 本轮不接

说明：

1. AD0 接地时通常地址为 `0x68`。
2. 若你实物板上 AD0 被拉高，则地址会变成 `0x69`，代码仍可兼容探测，但接地更统一。

### 5.4 MAX30102

建议接法：

1. 3V3 -> VIN
2. GND -> GND
3. D4(GPIO5) -> SDA
4. D5(GPIO6) -> SCL
5. INT 本轮先不接

说明：

1. 虽然独立 VOFA 环境曾经用过 D2/D3，但整机版不建议继续保留那套独立接法。
2. 整机版建议直接并回共享 I2C，减少线束和代码口径分裂。

### 5.5 DRV2605L + LRA

建议接法：

1. 3V3 -> DRV2605L VIN
2. GND -> DRV2605L GND
3. D6(GPIO43) -> DRV2605L SDA
4. D7(GPIO44) -> DRV2605L SCL
5. DRV2605L OUT+ -> LRA 正极
6. DRV2605L OUT- -> LRA 负极

说明：

1. 这里直接沿用独立 LRA 实验环境的 I2C 口径，能减少后续整合工作量。
2. 这也是本轮更稳妥的整机方案，不需要等出问题后再把 DRV2605L 拆出去。

### 5.6 薄膜压力模块

假设模块引脚为 `A0 / D0 / GND / VCC`，本轮只接模拟量：

1. VCC -> 3V3
2. GND -> GND
3. A0 -> XIAO D0 / A0 / GPIO1
4. D0 -> 不接

说明：

1. 你要的是“传递压感模拟数据”，所以必须用 A0，不建议本轮接 D0 作为主输入。
2. D0 通常只是阈值比较后的二值输出，不适合表达连续压力变化。

### 5.7 RGB 共阴极三色 LED

推荐接法：

1. 共阴极公共脚 -> GND
2. 红色阳极 -> 串联限流电阻 -> XIAO D8 / GPIO7
3. 绿色阳极 -> 串联限流电阻 -> XIAO D9 / GPIO8
4. 蓝色阳极 -> 串联限流电阻 -> XIAO D10 / GPIO9

限流建议：

1. 每个颜色都要单独串一个电阻，不允许三个颜色共用一个电阻。
2. 建议首轮使用 `220R` 到 `1k`。
3. 如果只需要状态提示、亮度不必很高，`330R` 或 `470R` 更稳妥。

共阴极逻辑说明：

1. GPIO 输出高电平时，该颜色导通点亮。
2. GPIO 输出低电平时，该颜色熄灭。
3. 这和当前板载用户灯 GPIO21 的低电平点亮逻辑不同，不要混淆。

## 6. 最终推荐引脚占用一览

| 功能 | XIAO 引脚 | GPIO | 去向 |
|---|---|---:|---|
| 功能 | XIAO 引脚 | GPIO | 去向 |
|---|---|---:|---|
| 主 I2C SDA | D4 | 5 | MPU6050 SDA + MAX30102 SDA |
| 主 I2C SCL | D5 | 6 | MPU6050 SCL + MAX30102 SCL |
| 副 I2C SDA | D6 | 43 | DRV2605L SDA |
| 副 I2C SCL | D7 | 44 | DRV2605L SCL |
| 压力模拟输入 | D0 / A0 | 1 | 薄膜压力模块 A0 |
| RGB 红 | D8 | 7 | RGB LED 红色阳极（串电阻） |
| RGB 绿 | D9 | 8 | RGB LED 绿色阳极（串电阻） |
| RGB 蓝 | D10 | 9 | RGB LED 蓝色阳极（串电阻） |
| 板载用户灯 | 板载 | 21 | 保留给系统状态，不外接 |

## 7. 保留和空闲引脚

按当前方案，以下引脚仍空闲：

1. D1 / A1 / GPIO2
2. D2 / GPIO3
3. D3 / GPIO4

这意味着：

1. 若后面你又要接数字中断、按键或备用状态灯，还有余量。
2. 后续若还要加按键、中断线或额外状态灯，仍有扩展余量。

## 8. 重要注意事项

### 8.1 关于 I2C 上拉

IMU、MAX30102、DRV2605L 模块板上常常自带上拉电阻。

因此：

1. 可以先直接并线验证。
2. 若后面发现波形不稳、通信偶发失败，再排查总线上拉是否过重。

### 8.2 关于供电能力

1. MAX30102、MPU6050、DRV2605L、压力模块都挂在 3V3 上时，首轮小 Demo 一般可行。
2. 但 LRA 震动时会带来瞬时电流扰动，若出现 PPG 明显受干扰，后续要重点看供电和地线布局。

### 8.3 关于 RGB LED

1. 一定要串联限流电阻。
2. 不要直接把 LED 阳极硬接 GPIO。

### 8.4 关于压力模块

1. 本轮只用 A0。
2. D0 暂不接，避免把比较器输出误当成连续压力数据。

## 9. 本轮最终建议

如果你现在就开始搭完整 Demo，建议直接按这版接：

1. IMU、PPG 共用 D4/D5 主 I2C
2. DRV2605L 独立使用 D6/D7 副 I2C
3. 压力模块 A0 接 D0/A0(GPIO1)
4. RGB 共阴极 LED 接 D8/D9/D10，并各自串电阻

这是当前在“尽量不冲突、便于排障、同时贴近现有独立实验代码口径”三点之间最平衡的一版。
