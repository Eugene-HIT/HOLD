# 2026-08-12 原理图接线冻结与飞线点保留建议

## 文档标题
HOLD 下一版主板原理图接线冻结建议与外接飞线点定义

## 创建时间
2026-08-12

## 最后更新时间
2026-08-12

## 文档目的
在开始正式绘制主板原理图前，冻结当前版本最重要的网络分配，避免在画图过程中再次漂移。同时明确哪些模块直接画在 PCB 上，哪些只保留外接焊点。

## 本版结论

### 1. 直接画在 PCB 上的部分
1. XIAO ESP32S3 Plus 基座。
2. MPU6050 IMU。
3. MAX30102 PPG。
4. DRV2605L 驱动芯片。
5. 热反馈驱动电路，包括 MOSFET、栅极电阻、下拉电阻和必要保护。
6. FSR 前端分压与滤波电路。
7. RGB 状态灯与限流电阻。
8. 电源路径、去耦、电池输入、测试点。

### 2. 仅保留外接焊点或连接点的部分
1. FSR 传感片本体。
2. MOTOR/LRA 执行器本体。
3. HEAT 发热片本体。

结论：

本版不要再给 IMU、PPG、DRV 芯片本体预留飞线验证接口，它们应直接进入正式 PCB 连接。需要预留飞线的对象只保留给贴附式、分体式、机械位置敏感的外设本体。

## 推荐冻结的主控引脚口径

### 电源与公共网络
1. BAT+：电池正极主电源网络。
2. BAT- / GND：系统地。
3. 3V3：传感器与逻辑主电源。

### I2C 主总线
1. D4(GPIO5)：SDA。
2. D5(GPIO6)：SCL。

本版建议挂载到主 I2C 的器件：
1. MPU6050。
2. MAX30102。
3. DRV2605L。

说明：

当前工程历史上同时存在“DRV2605L 独立副 I2C”和“DRV2605L 挂主 I2C”两种口径，但你这轮已经明确要开始正式画原理图，并且仅保留 FSR、MOTOR、HEAT 三类外接点，因此本版建议优先采用更利于收敛原理图的单主 I2C 方案。

### 模拟与控制脚
1. D0/A0(GPIO1)：FSR 模拟采样 ADC。
2. D1/A1(GPIO2)：HEAT_CTRL，输出到热反馈低边 MOSFET Gate，仅作为控制信号，不直接接加热片。
3. D8(GPIO7)：RGB_R。
4. D9(GPIO8)：RGB_G。
5. D10(GPIO9)：RGB_B。

### 可选控制脚
1. D6(GPIO43)：TPS_EN，可选保留给传感器电源门控。
2. D7(GPIO44)：M_EN，可选保留给 DRV2605L 使能或触觉电源门控。

说明：

如果你这一版不再强调独立门控，这两个脚可以先保留到原理图中，但不必让它们成为第一优先级。优先冻结的是 I2C、FSR ADC、HEAT_CTRL、RGB。

## 原理图连接建议

### 1. XIAO ESP32S3 Plus
1. BAT+ 接电池正极网络。
2. BAT- 接系统地。
3. 3V3 输出到 IMU、PPG、DRV2605L、RGB、FSR 前端等低压逻辑部分。
4. D4/D5 作为全板主 I2C。
5. D0/A0 作为 FSR 模拟输入。
6. D1/A1 作为热反馈控制。
7. D8/D9/D10 作为 RGB 三色控制。

### 2. MPU6050
1. VCC -> 3V3。
2. GND -> GND。
3. SDA -> D4(GPIO5)。
4. SCL -> D5(GPIO6)。
5. AD0 默认接地，统一使用 0x68。
6. INT 可先留测试焊盘，不作为第一版必接项。

### 3. MAX30102
1. 若使用带稳压和电平转换的 MAX30102 模块，可按模块丝印 VIN -> 3V3、SDA -> D4、SCL -> D5。
2. 若使用裸 MAX30102EFD+T 芯片，则不要直接按 VIN=3V3 的模块口径画。
3. 裸芯片方案下，VDD 必须接 1V8 逻辑电源。
4. 裸芯片方案下，LED 供电端单独接 PPG_LED 电源，电压按官方器件要求配置，不能直接沿用“模块 VIN”表述。
5. 裸芯片方案下，SDA/SCL/INT 应按 1V8 逻辑域处理，再与主控侧电平匹配。
6. 芯片附近就近放置去耦，走线优先短而干净。

### 4. DRV2605L
1. VDD -> 3V3。
2. GND -> GND。
3. SDA -> D4(GPIO5)。
4. SCL -> D5(GPIO6)。
5. EN 若使用则接 D7(GPIO44)，否则可固定上拉使能。
6. OUT+ -> MOTOR+ 外接焊点。
7. OUT- -> MOTOR- 外接焊点。

说明：

第一版真正需要外接的是马达本体，不是 DRV2605L 的 I2C。

### 5. FSR 前端
1. FSR 本体保留为外接件。
2. FSR 的分压电阻、限流和滤波电容放在主板上。
3. ADC 采样节点只在板内存在，不建议作为外部飞线点引出。
4. ADC 采样节点最终接 D0/A0(GPIO1)。

说明：

如果你使用的是裸 FSR 片，建议只把 FSR 两端作为外接焊点，不要把 ADC 节点拉到板外。模拟高阻节点留在板内更稳。

### 6. 热反馈驱动
1. D1/A1(GPIO2) -> 栅极串联电阻 -> AO3400A Gate。
2. Gate 同时通过下拉电阻到 GND，保证上电默认关闭。
3. AO3400A Source -> GND。
4. AO3400A Drain -> HEAT- 外接焊点。
5. 加热片另一端 -> BAT+ 外接焊点。

说明：

真正外接的是加热片两端，不是 HEAT_CTRL 控制线。HEAT_CTRL 必须留在板内。

### 7. RGB 共阴极状态灯
1. 共阴极 -> GND。
2. R 阳极 -> 限流电阻 -> D8(GPIO7)。
3. G 阳极 -> 限流电阻 -> D9(GPIO8)。
4. B 阳极 -> 限流电阻 -> D10(GPIO9)。

## 本版应保留的外接点

### 1. FSR 外接点
推荐只保留 2 个焊点：
1. FSR_A。
2. FSR_B。

说明：

不要把 ADC_PIN 作为第三个飞线点引出。ADC 节点应保留在主板本地前端。

### 2. MOTOR 外接点
推荐保留 2 个焊点：
1. MOTOR+。
2. MOTOR-。

说明：

它们直接对应 DRV2605L 的 OUT+ 与 OUT-。

### 3. HEAT 外接点
推荐保留 2 个焊点：
1. BAT+。
2. HEAT-。

说明：

加热片本体接在 BAT+ 与 HEAT- 之间。不要把 GPIO2 或 MOS Gate 作为外部飞线接口。

## 本版不建议保留的飞线点
1. MPU6050 SDA/SCL。
2. MAX30102 SDA/SCL。
3. DRV2605L SDA/SCL。
4. RGB R/G/B。
5. HEAT_CTRL。
6. ADC_PIN。

原因：

这些都属于板内逻辑和板内前端网络。若继续把它们也按飞线思路处理，原理图会再次退化成验证板，不利于下一版 PCB 收敛。

## 推荐网络命名
1. I2C_SDA。
2. I2C_SCL。
3. FSR_ADC。
4. HEAT_CTRL。
5. HEAT_NEG。
6. MOTOR_P。
7. MOTOR_N。
8. RGB_R。
9. RGB_G。
10. RGB_B。
11. BAT_PLUS。
12. GND。
13. PPG_INT。
14. TPS_EN。
15. HAPTIC_EN。

## 画图时的优先级
1. 先把 XIAO Plus、电池、电源、GND、3V3 画完整。
2. 再画主 I2C 上的 MPU6050、MAX30102、DRV2605L。
3. 再画 FSR 前端与 D0/A0。
4. 再画 HEAT 低边驱动与外接焊点。
5. 最后画 RGB、测试点和可选 EN 控制。

## 当前建议的最终口径
1. 所有传感与驱动芯片本体直接上 PCB。
2. 真正保留为外接件的只剩 FSR 本体、MOTOR 本体、HEAT 本体。
3. FSR 保留 2 线外接，不把 ADC 节点拉出板外。
4. MOTOR 保留 2 线外接，对应 DRV2605L 输出。
5. HEAT 保留 2 线外接，对应 BAT+ 与 HEAT-。
6. MAX30102 若选用裸 MAX30102EFD+T，原理图必须显式区分 1V8 逻辑电源与 PPG LED 供电，不能按现成模块的 3V3/VIN 接法照搬。
