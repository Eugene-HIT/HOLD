# HOLD miniapp function list for swimlane design

## L0 核心闭环

- 用户目标
  - 戴上设备
  - 连接设备
  - 完成基础校准
  - 开始呼吸引导
  - 看到实时状态
  - 停止引导或断开设备

- 小程序首页
  - 扫描并连接
  - 显示连接状态
  - 显示校准状态
  - 开始基础校准
  - 开启/停止呼吸引导
  - 显示实时指标
  - 显示关键提示

- 硬件
  - BLE 广播
  - BLE 连接
  - Notify 状态上报
  - Write 命令接收
  - DRV2605 呼吸震动
  - DRV2605 校准脉冲
  - 传感器状态采样

## L1 首页信息架构

- 连接区
  - 设备名
  - 蓝牙适配器状态
  - BLE 连接状态
  - 主操作：扫描并连接
  - 辅操作：断开连接

- 校准与引导区
  - 当前引导标题
  - 当前引导说明
  - 当前链路提示
  - 基础校准按钮
  - 呼吸引导按钮

- 实时指标区
  - 呼吸 bpm
  - 心率 bpm
  - beat 数
  - 运动状态
  - 呼吸/校准阶段
  - 传感器型号或轴向

- 诊断入口
  - 查看调试曲线
  - 删除本地调试缓存

## L2 调试页功能

- 链路诊断
  - BLE adapter 状态
  - 设备连接状态
  - 设备名
  - 设备状态
  - 最近包类型
  - 当前引导状态

- BLE 操作
  - 扫描并连接
  - 断开连接
  - 清空调试窗口
  - 开始/停止呼吸反馈
  - 基础校准

- 数据窗口
  - 呼吸 bpm
  - 心率 bpm
  - motion
  - beat count
  - 状态 / 传感器
  - haptic ready
  - raw text
  - raw hex

- 云函数验证
  - button press 事件提交
  - 云端存储路径
  - LLM 返回摘要
  - 错误提示

## L3 异常与恢复

- 蓝牙未开启
  - 首页提示打开手机蓝牙和小程序权限
  - 保留扫描按钮

- 未发现设备
  - 显示正在寻找 `HOLD-INTEGRATED`
  - 允许重新扫描

- 找不到服务
  - 提示烧录 integrated BLE 固件
  - 引导进入调试页

- 找不到 notify 特征
  - 提示固件协议不匹配
  - 保留 raw/hex 调试入口

- 找不到 command 特征
  - 禁用校准和呼吸按钮
  - 提示当前固件没有命令写入特征

- 收到无法解析数据
  - 显示 binary 包长度和 hex
  - 不阻塞连接状态

## L4 后续增强

- 呼吸算法
  - 将 IMU 呼吸估计合并进 integrated firmware
  - 上报真实 respiration bpm
  - 上报 inhale/exhale 置信度

- 佩戴质量
  - PPG contact 状态
  - 压力贴合等级
  - 佩戴不稳提醒

- 引导体验
  - 呼吸节奏可选
  - 震动强度可调
  - 校准倒计时
  - 完成后的轻提示

- 数据闭环
  - 本地 session 记录
  - 云端事件同步
  - 调试日志导出
