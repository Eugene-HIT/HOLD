# log 目录说明

该目录用于记录本项目开发过程中的调试信息、实验记录、参数变更与阶段性结论。

推荐子目录：
- system：agent、prompt、工作区规则、流程调整等系统级记录
- firmware：固件开发、编译、烧录、串口验证等记录
- dev：面向某个模块或功能的临时开发要求文档、开发前约束说明、阶段性开发草稿

建议内容：
- 环境搭建记录
- 接线与器件变更记录
- 传感器测试记录
- 反馈器件联调记录
- 问题排查记录
- 参数调整记录

建议文件命名格式：
- 2026-05-22-环境搭建.md
- 2026-05-22-传感器测试.md
- 2026-05-22-联调记录.md

## dev 目录建议结构

当内容属于“为了推进某个模块或某个功能而临时创建的开发要求文档”时，建议使用以下层级：

- log/dev/日期/模块/功能/文档.md

示例：
- log/dev/2026-05-23/max30102/raw-read/MAX30102原始数据读取开发要求.md

使用建议：
- 日期层用于区分同一天的阶段任务
- 模块层用于区分传感器、通信、反馈、结构等主题
- 功能层用于区分原始数据读取、滤波验证、联调、日志等具体任务
- 文档文件名应直接体现任务目标，避免出现“新建文档1”之类无意义命名
