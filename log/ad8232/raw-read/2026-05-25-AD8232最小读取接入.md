# 2026-05-25 AD8232 最小读取接入

## 任务名称
为当前 XIAO ESP32S3 根工程接入 AD8232 生物电模块 OUTPUT 模拟量最小读取链路

## 修改文件
- include/ad8232_raw_reader.h
- src/ad8232_raw_reader.cpp
- include/project_config.h
- src/main.cpp

## 主要变更
- 新增独立的 Ad8232RawReader 模块，负责 AD8232 OUTPUT 模拟值的最小 ADC 读取
- 在项目配置中新增 AD8232 的 ADC 引脚、ADC 分辨率、内部轮询节拍和串口输出节拍
- 在主程序中新增 AD8232 接线提示、初始化入口和周期输出入口
- 当前串口输出已收敛为 ECG 最小状态行，输出最近原始值、窗口均值、窗口最小值、窗口最大值和峰峰值
- 首轮实现只覆盖 OUTPUT 主路径，不把 LO+ / LO- 做成必需逻辑
- 新增 VOFA+ 兼容输出模式，开启后串口只输出单列原始 ADC 数值，避免文本日志污染绘图流

## 实现思路
- 继续沿用当前工程既有的“独立 reader 模块 + main 调度”结构，不把 AD8232 读取逻辑直接堆进主循环
- 为了适配 ECG 相比压力模块更高的时间分辨率需求，将 AD8232 内部轮询节拍单独设置为 4ms，约等于 250Hz
- 串口层不输出每一个采样点，避免直接淹没现有日志；首轮改为每 100ms 输出一行窗口统计，先确认链路是否活着和波形是否在变化
- `SDN` 在接线层固定要求接 3V3，避免模块意外进入关断状态
- LO+ / LO- 暂时只保留在接线建议中，待后续确有导联脱落判断需求时再接入数字引脚

## 当前接线口径
- XIAO 3V3 -> AD8232 3.3v
- XIAO GND -> AD8232 GND
- XIAO D1 / A1 / GPIO2 -> AD8232 OUTPUT
- XIAO 3V3 -> AD8232 SDN
- AD8232 LO+ / LO- 本阶段可先不接

## 当前串口输出口径
- 启动阶段会输出接线提示，例如：
  - [wiring] XIAO D1/A1(GPIO2) -> AD8232 OUTPUT
  - [wiring] XIAO 3V3 -> AD8232 SDN
- 初始化完成后会输出：
  - [ecg] ADC=GPIO2 | sample_interval=4ms | log_interval=100ms
  - [ecg] AD8232 ready | waiting for electrode contact and waveform changes
- 运行阶段周期输出：
  - [ecg] seq=2361 | up=10034ms | samples=14 | raw=263 | mean=71 | min=0 | max=263 | p2p=263
  - [ecg] seq=2386 | up=10134ms | samples=25 | raw=181 | mean=62 | min=0 | max=207 | p2p=207

## VOFA+ 输出口径
- 当前已在项目配置中开启 `kEnableAd8232VofaStream = true`
- 开启后，会关闭其余传感器和文本状态日志，只保留 AD8232 原始 ADC 单列输出
- 输出格式为每行一个整数，例如：
  - 2063
  - 2271
  - 2168
- 该格式可直接用于 VOFA+ 的 FireWater 纯文本波形显示

## 当前结论
- 当前工程已具备 AD8232 最小读取能力
- 当前接入路线明确为 OUTPUT -> ADC -> 窗口统计 -> 串口输出
- 当前固件已经可以作为下一步电极贴附和接触质量验证的基础版本
- 当前输出只能证明“能读到变化的数据”，还不能证明已经拿到高质量 ECG 波形

## 风险与待确认事项
- 当前串口窗口统计中多次出现 min=0，说明当前采样仍可能处于未贴附、接触不良、模块偏置不稳或噪声较大的状态
- 若后续电极贴附后仍长期看到 min=0 且 p2p 异常，应优先排查电极贴位置、导联线对应关系、模块供电与 OUTPUT 接线
- 当前实现故意没有直接上 R 峰检测或 HRV，避免在原始波形质量尚未确认时引入算法误判
