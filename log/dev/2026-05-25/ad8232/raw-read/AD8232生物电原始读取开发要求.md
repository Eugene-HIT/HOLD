- 所属模块：AD8232 / 单导联生物电 ECG 前端原始读取
- 文档用途：指导当前工程完成 XIAO ESP32-S3 对 AD8232 心电模块的最小接入验证，优先完成接线确认、原始波形读取和串口可观测输出
- 输入：XIAO ESP32-S3 开发板、AD8232 心电模块、三片电极贴、现有 PlatformIO 根工程、串口监视器、模块接线与电极佩戴信息
- 输出：可稳定读取 AD8232 OUTPUT 模拟波形的开发要求、引脚结论、电极贴法建议、算法调研结论与最小验证方案

## 1. 文档目的
本文件用于约束当前阶段的 AD8232 模块接入工作。本阶段目标不是做临床级心电判读、心律失常自动分类或完整情绪识别，而是先完成“模块接线 -> 电极贴附 -> ADC 连续采样 -> 串口看到波形变化”的最小闭环。

本阶段完成后，应能确认：
- XIAO ESP32-S3 存在合适的 ADC 引脚可读取 AD8232 的模拟输出
- 三电极接法与模块导联定义一致
- AD8232 在当前供电和接线下能够稳定输出心电相关波形
- 串口输出足以区分静置、接触不良、导联脱落和稳定心跳波形这几种最小状态

## 2. 需求背景
当前项目上位目标是“焦虑检测及引导平复装置”，开发指南强调应优先完成“可用、可测、可记录”的 MVP 链路。与前序 MAX30102 和 ICS43434 一样，AD8232 当前阶段的职责不是直接得出焦虑结论，而是先确认心电生物电通路是否可用，为后续心率、R-R 间期、HRV 与节律引导策略提供基础数据。

根据当前已确认资料：
- AD8232 是单导联心电前端，输出为适合 MCU ADC 读取的模拟波形
- AD8232 支持两电极或三电极配置，但当前实物模块和三片电极贴更适合按三电极方式接入
- 模块板上常见引脚为 `GND`、`3.3v`、`OUTPUT`、`LO-`、`LO+`、`SDN`
- `OUTPUT` 为主信号输出，`LO+`/`LO-` 为导联脱落检测输出，`SDN` 低电平会关断芯片
- AD8232 官方资料明确其应用面向 ECG 和其他 biopotential 测量，适合后续做 QRS/R 峰、心率和 HRV 等算法，但当前模块只是单导联，不能替代多导联临床 ECG

## 3. 本阶段目标定义
本阶段必须完成以下目标：

1. 硬件接线确认
- 明确 AD8232 模块供电、电极、输出和导联脱落引脚含义
- 明确本阶段主路径只要求 `OUTPUT -> ADC`
- 明确 `LO+`、`LO-` 是否接入为可选项，而不是首轮必须项

2. 电极贴法确认
- 明确三片电极在三电极模式中的职责
- 明确 RA、LA、RL 与模块内部导联关系
- 明确首轮最小验证的推荐贴附位置

3. ADC 读取路径确认
- 选择一个不与现有模块冲突的 ADC 引脚读取 `OUTPUT`
- 确认 `SDN` 必须保持高电平或等效启用状态
- 建立连续采样和最小串口可观测输出

4. 算法空间调研
- 明确 AD8232 单导联 ECG 在当前项目中可支持哪些后续算法
- 区分“今晚就能做的最小数据读取”和“后续才能做的节律/HRV分析”
- 不夸大单导联 ECG 的临床能力边界

## 4. 范围说明

### 4.1 本阶段包含
- AD8232 模块供电与引脚验证
- 三电极贴的最小贴附方案确认
- `OUTPUT` 模拟量 ADC 采样
- 可选的 `LO+` / `LO-` 导联脱落状态接入规划
- 串口输出原始或轻量处理后的心电观测信息
- 与项目背景相关的算法调研结论归纳

### 4.2 本阶段不包含

- 心律失常自动分类
- ST 段、QT 间期等医学判读
- 基于 ECG 单模态直接判断焦虑状态
- 长时间 Holter 级记录

## 6. 约束条件
- 今晚目标只允许聚焦“能读到数据”，不允许把算法目标扩展到临床判读
- 首轮实现必须优先围绕 `OUTPUT` 模拟量读取，不允许一上来就把重点放在复杂特征提取上
- 首轮优先使用 3.3V 供电，与模块丝印保持一致
- 若需要使用 `LO+` / `LO-`，仅把它们作为导联接触状态辅助信号，不把其输出当作心电波形本身
- `SDN` 不能悬置到可能进入关断的状态，必须明确保持启用
- 接人体电极的测试必须优先考虑隔离和供电方式，不允许把当前原型包装成医疗设备
- 单导联模块后续最多支持轻量节律/HRV/趋势分析，不允许在文档中将其描述为可靠的临床诊断系统

## 8. 引脚与接线结论

### 8.1 AD8232 模块已确认引脚含义
结合用户提供图片和 AD8232 资料，当前板载引脚按以下理解处理：

| 模块丝印 | 含义 | 本阶段是否必须接入 | 说明 |
| --- | --- | --- | --- |
| GND | 电源地 | 是 | 共地 |
| 3.3v | 模块供电 | 是 | 首轮固定 3.3V |
| OUTPUT | 经模拟前端调理后的心电输出 | 是 | 接 MCU ADC |
| LO- | 导联脱落检测输出 | 否，可选 | 可接数字输入辅助判断 |
| LO+ | 导联脱落检测输出 | 否，可选 | 可接数字输入辅助判断 |
| SDN | 关断控制输入 | 是，必须定义状态 | 低电平进入关断 |

### 8.2 XIAO ESP32-S3 推荐首轮引脚方案
结合当前工程已使用引脚，建议首轮优先使用：

- XIAO 3V3 -> AD8232 3.3v
- XIAO GND -> AD8232 GND
- XIAO A1 / D1 / GPIO2 -> AD8232 OUTPUT
- XIAO D2 / GPIO3 -> AD8232 LO+
- XIAO D3 / GPIO4 -> AD8232 LO-
- XIAO 3V3 -> AD8232 SDN

说明：
- `OUTPUT` 需要占用一个 ADC 引脚，当前推荐 A1 / D1 / GPIO2，避免与已规划给压力模块的 A0 / D0 / GPIO1 直接重叠
- `LO+` 与 `LO-` 若首轮想再简化，可以先不接，只保留 `OUTPUT`
- `SDN` 首轮建议直接固定接 3V3，避免额外占用 GPIO，并确保模块保持工作状态
- 当前若仍保留麦克风接线，应继续避免占用 D8-D10

### 8.3 当前最小接线建议
若以“今晚只要读到数据”为唯一目标，建议先按以下最小接线：

- 3V3 -> 3.3v
- GND -> GND
- A1 / D1 / GPIO2 -> OUTPUT
- 3V3 -> SDN

可选增强：

- D2 / GPIO3 -> LO+
- D3 / GPIO4 -> LO-

## 9. 三电极贴与佩戴建议

### 9.1 导联角色理解
当前三电极模式建议按以下角色理解：

- RA：右臂导联，作为一个差分输入端
- LA：左臂导联，作为另一个差分输入端
- RL：右腿导联，作为参考/驱动电极，用于抑制共模干扰

结合用户图片中的芯片引脚说明：
- `+IN` 通常对应 LA
- `IN` 通常对应 RA
- `RLD` 对应 RL

### 9.2 首轮推荐贴附位置
结合单导联 ECG 最小验证经验，推荐首轮按以下位置贴附：

- LA：左锁骨下方、左胸上部
- RA：右锁骨下方、右胸上部
- RL：右下腹或左下腹偏下位置，尽量远离心脏区域

说明：
- RL 虽常被称为“右腿”，但首轮并不一定真的贴腿上；只要作为参考电极并远离主要测量区域即可
- 首轮验证优先采用胸前贴法，而不是四肢远距离贴法，通常更容易拿到稳定波形
- 应尽量避开大块肌肉剧烈运动区域，减少肌电干扰

### 9.3 导联线与电极片注意事项
- 如果模块附带 3.5mm 导联线，应优先使用配套导联线，不建议直接手改芯片内部电极焊盘
- 导联线颜色在不同卖家版本中可能不同，不能仅凭颜色判断 RA/LA/RL，必须以实物说明或导通关系为准
- 若电极贴接触不良，`LO+` / `LO-` 可能提示导联脱落，同时 `OUTPUT` 波形会明显失真或漂移

## 10. 生物电算法调研结论

### 10.1 AD8232 单导联 ECG 后续可支持的算法方向
在本项目背景下，AD8232 后续最有价值的算法方向包括：

1. R 峰检测 / QRS 检测
- 这是后续所有节律类指标的基础
- 常见轻量方法包括 Pan-Tompkins、Hamilton-Tompkins、导数+阈值、自适应峰值检测

2. 心率与 R-R 间期
- 从 R 峰间距直接得到 BPM 和 beat-to-beat interval
- 这是当前项目最现实的第一层可用指标

3. HRV 指标
- 可从 R-R 间期进一步计算 RMSSD、SDNN、pNN50、LF/HF、SD1/SD2 等
- 这些指标与自主神经调节、压力和恢复状态研究相关，但解释高度依赖时长、呼吸、姿势和伪迹处理

4. 节律异常初筛
- 后续可做“节律是否明显不规则”的工程级提醒
- 但单导联模块不适合直接做严肃医学诊断

5. ECG 导出的辅助指标
- 例如 Poincaré 图、非线性复杂度、与呼吸节律引导联动的趋势观察
- 这些更适合后续阶段，不属于今晚最小目标

### 10.2 对当前项目最相关的结论
结合焦虑检测与平复引导这个项目背景，AD8232 最适合承担的角色是：

- 提供更准确的 beat-to-beat 节律信息
- 为 HRV 相关趋势分析提供原始依据
- 与呼吸引导模块或其他传感器联合使用时，提供“紧张/恢复趋势”的一部分证据

它不适合单独承担以下职责：

- 单独判断用户是否焦虑
- 单导联下可靠诊断心律失常或心肌缺血
- 在强运动、强肌电干扰场景下直接输出高可信医学结论

### 10.3 今晚不该做的算法扩展
- 不进入 ST/QT/P 波精细检测
- 不上复杂时频特征和机器学习分类
- 不把 LF/HF 比值直接当作“交感/副交感平衡”唯一结论
- 不把短时 HRV 结果过度解释为心理状态诊断结果

## 11. 参考算法结论

### 11.1 适合本项目的后续算法优先级
建议后续优先级如下：

1. 原始波形稳定读取
2. R 峰检测
3. BPM 与 R-R 间期
4. 短时 HRV，例如 RMSSD / SDNN
5. 非线性图形或更复杂特征

### 11.2 当前最推荐的基础算法
- QRS/R 峰检测：Pan-Tompkins 或 Hamilton-Tompkins 风格轻量算法
- 后续 HRV：先做 RMSSD、SDNN、pNN50
- 若未来要做图形化分析，可再增加 Poincaré SD1/SD2

理由：
- 这些算法计算成本低，适合当前 XIAO ESP32-S3 实时运行
- 它们与“焦虑/紧张趋势观察”比复杂形态学判读更相关
- 其前提条件明确：必须先有稳定 R 峰和较干净的 R-R 序列

## 12. 安全与工程边界
- 当前模块和当前原型不能视为医疗设备
- 接人体电极时，必须优先使用低压、独立、安全的供电与调试方式
- 当前阶段只建议做原型验证，不建议把接人体电极的原型长期挂接在高风险供电环境中
- 有植入式医疗设备、心脏疾病史或其他高风险情况时，不应以原型设备进行自测

说明：
- 关于人体连接设备的严格安全规范，应以医疗电气安全标准和专业设备要求为准；当前资料不足以把现有原型定义为安全合规人体设备
- 因此当前文档只能给出工程验证层面的保守建议，不能给出医疗安全合规背书

## 13. 推荐开发流程

1. 确认模块引脚与导联线
- 先确认 `OUTPUT`、`SDN`、`LO+`、`LO-` 丝印
- 再确认三导联线对应 RA/LA/RL 的实物定义

2. 先做最小硬件闭环
- 先接 `3.3v`、`GND`、`OUTPUT`、`SDN`
- 三片电极按推荐位置贴好

3. 做原始 ADC 读取
- 周期性执行 analogRead
- 先验证是否能看到明显起伏而不是固定值

4. 视需要再接入导联脱落状态
- 若波形始终异常，再把 `LO+` / `LO-` 接入数字脚辅助排查

5. 收敛串口输出
- 今晚只输出原始波形相关最小信息
- 优先确认“能读到波形”，而不是先确认“算得准”

## 14. 推荐初始验证策略
- 第一轮只验证 `OUTPUT` 是否能持续输出非固定 ADC 值
- 静止、贴附稳定时，应能看到周期性起伏，而不是纯随机噪声
- 若电极脱落，波形应明显失真，且若接入 `LO+` / `LO-` 可看到导联状态变化
- 若始终只有漂移和噪声，优先排查电极位置、接触质量、导联线对应关系、`SDN` 状态和 ADC 引脚接法

## 15. 验收标准
满足以下条件，才算本阶段完成：

1. 已明确并记录 AD8232 的主接线和可选接线
2. 已明确并记录 RA、LA、RL 三电极的建议贴法
3. 已明确并记录 `OUTPUT` 为首轮主路径、`SDN` 必须保持工作状态
4. 串口中能看到持续变化的 ADC 读数或等效波形输出
5. 已明确 AD8232 后续可支持的算法范围与边界

## 16. 风险与待确认事项

### 16.1 风险
- 导联线颜色和 RA/LA/RL 对应关系在不同卖家版本中可能不同
- 仅凭商品图无法百分百确认模块板上是否已对 `SDN` 做默认上拉，因此首轮不应依赖“悬空也能工作”
- 肌电、体动、电极接触不良和电源噪声都会显著污染 ECG 波形
- 单导联 ECG 的算法输出很容易被误解为医疗结论，必须严格控制表述

### 16.2 待确认事项
- 用户手中这版模块的三导联线是否有明确 RA/LA/RL 标识
- 用户今晚是否计划在 USB 连接调试状态下直接贴电极做人体测试；若是，需要用户自行确认其可接受的实验风险边界
- 当前用户更倾向于胸前贴法，还是已有固定佩戴位置方案；这会影响后续波形质量和项目落地方式
