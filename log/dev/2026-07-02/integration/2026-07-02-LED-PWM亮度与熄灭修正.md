# LED PWM 亮度与熄灭修正

## 记录时间
- 日期：2026-07-02
- 模块：integration / LED feedback

## 任务名称
- 修正整机环境中 RGB LED 的 PWM 常亮亮度过暗与脉冲无法完全熄灭问题

## 修改文件
- src/integration/led_feedback_manager.cpp

## 主要变更
1. 新增常量占空比定义，明确 `0` 表示熄灭，`255` 表示常亮满占空比。
2. 将黄灯常亮、绿灯常亮、蓝灯常亮从 `HIGH/LOW` 数字电平写法改为真实 PWM 占空比写法，避免常亮态只有 `1/255` 亮度。
3. 将平滑脉冲 `pulseSoft` 与 `pulseSlow` 的最小值从非零改为 `0.0f`，允许灯效在周期低谷彻底熄灭。
4. 保持现有平滑 PWM 方案不变，仅修正亮度表达方式，避免扩大改动范围。

## 实现思路
- 本次问题根因不是 LEDC 初始化或状态机映射错误，而是 PWM 输出层把 `HIGH` 当成“全亮”使用。
- 在 `ledcWrite()` 语义下，`HIGH` 仅等于占空比 `1`，所以常亮颜色会极暗。
- 同时，脉冲函数最小缩放值被抬高，导致闪烁最低谷仍有残余亮度，看起来“熄不干净”。
- 因此仅在 `led_feedback_manager.cpp` 内修正占空比常量与脉冲下限即可闭环。
