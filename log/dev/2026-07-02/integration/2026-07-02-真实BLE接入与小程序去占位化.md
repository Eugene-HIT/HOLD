# 真实BLE接入与小程序去占位化

## 记录时间
- 日期：2026-07-02
- 模块：integration / BLE / miniapp debug

## 任务名称
- 将整机环境从模拟 BLE 连接切换到真实 GATT 服务，并移除小程序调试页中的演示与占位数据

## 修改文件
- src/integration/ble_link_manager.cpp
- web/utils/ble-debug-protocol.js
- web/pages/index/index.js
- web/pages/index/index.wxml

## 主要变更
1. `ble_link_manager.cpp` 不再使用 1.5 秒后自动置为已连接的模拟逻辑。
2. 新增真实 ESP32 BLE GATT 服务：
   - Service UUID: `19B10010-E8F2-537E-4F6C-D104768A1214`
   - Notify Characteristic UUID: `19B10011-E8F2-537E-4F6C-D104768A1214`
   - Command Characteristic UUID: `19B10012-E8F2-537E-4F6C-D104768A1214`
3. 整机设备名改为 `HOLD-INTEGRATED`，连接与断连事件现在由真实 BLE 回调驱动状态机。
4. 所有 `device_state`、`resp_debug`、`active_realtime`、窗口摘要与调试日志消息，除串口打印外，同步通过 notify 特征值发给小程序。
5. 小程序 BLE 调试协议工具去掉演示波形和旧按钮事件兼容逻辑，只匹配 `HOLD-INTEGRATED`。
6. 小程序调试页去掉“加载演示波形”按钮，不再默认填充等待文案或模拟指标；未连接、断连或没有收到通知时窗口保持空白。

## 实现思路
- 当前任务重点是把“真实链路是否建立”作为运行前提，而不是继续靠模拟连接推进状态机。
- 因此固件侧必须先把 BLE 连接事件改成真实回调驱动，主状态机才能满足“只有连接后才运行”的要求。
- 小程序端则同步收紧：不再兼容旧测试按钮链路，不再提供本地演示数据，所有展示都以真实 notify 数据为准。
