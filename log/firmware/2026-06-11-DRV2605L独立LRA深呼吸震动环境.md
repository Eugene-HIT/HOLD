# 2026-06-11 DRV2605L 独立 LRA 深呼吸震动环境

## 任务名称
为 XIAO ESP32S3 新建独立 DRV2605L + LRA 呼吸震动实验环境，用于验证“深呼吸式强到弱”触感。

## 修改文件
- [platformio.ini](platformio.ini)
- [src/drv2605l_xiao_esp32s3_lra_breath/main.cpp](src/drv2605l_xiao_esp32s3_lra_breath/main.cpp)

## 主要变更
- 新增独立 env：`drv2605l_xiao_esp32s3_lra_breath`
- 环境引入 `Adafruit DRV2605 Library`
- 新增独立入口，仅负责：
  - 初始化独立 I2C
  - 初始化 DRV2605L
  - 切换到 LRA + RTP 实时播放模式
  - 按固定深呼吸节律输出震动包络
- 本环境明确避开现有两组线：
  - IMU：D4(GPIO5) / D5(GPIO6)
  - PPG：D2(GPIO3) / D3(GPIO4)
- 本环境改用：
  - D6(GPIO43) 作为 SDA
  - D7(GPIO44) 作为 SCL

## 当前节律参数
- 吸气阶段：4200ms，强到弱
- 呼气阶段：4200ms，强到弱
- 停顿阶段：900ms，停止震动
- 吸气 RTP：`0x68 -> 0x20`
- 呼气 RTP：`0x60 -> 0x18`
- 包络刷新周期：25ms

## 实现思路
- 先不把 IMU / PPG 状态机并进来，只验证最小闭环的触感是否正确
- 使用 DRV2605L 的 LRA 模式与 RTP 实时播放模式，而不是用 ROM 内置效果硬拼长呼吸节律
- 呼吸引导先采用固定节律，便于用户先判断三件事：
  - 强度是否够
  - 吸气/呼气阶段是否容易分辨
  - 节律是否像“深呼吸”而不是普通脉冲震动
- 当前不写死具体 LRA 型号参数，避免在未知额定电压和共振频率下过早做激进寄存器设定

## 接线说明
- XIAO 3V3 -> DRV2605L VIN
- XIAO GND -> DRV2605L GND
- XIAO D6(GPIO43) -> DRV2605L SDA
- XIAO D7(GPIO44) -> DRV2605L SCL
- DRV2605L OUT+ -> LRA 正极
- DRV2605L OUT- -> LRA 负极
