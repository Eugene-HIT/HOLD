# 2026-06-28 整机冒烟测试环境

## 任务名称
为 XIAO ESP32S3 提供一个一次性联调 IMU、PPG、压力、DRV2605L 与热反馈控制脚的最小冒烟测试工程。

## 修改文件
- [platformio.ini](platformio.ini)
- [src/xiao_esp32s3_full_smoke_test/main.cpp](src/xiao_esp32s3_full_smoke_test/main.cpp)

## 主要变更
- 新增独立 PlatformIO 环境 `xiao_esp32s3_full_smoke_test`。
- 新增统一冒烟入口，整合以下模块：
  - MPU6050
  - MAX30102
  - 薄膜压力模块
  - DRV2605L + LRA
  - 热反馈 PWM 控制脚
  - RGB 循环流水灯
- 启动阶段新增分段串口日志，并为主 I2C 增加超时，便于定位是 USB 串口、I2C 卡死还是加热负载导致的上电异常。
- 热反馈 PWM 改为上电先拉低，等待 5 秒后再输出 80% 占空比，优先确保启动阶段的串口和多模块初始化可观察。
- 串口统一输出一行状态，便于快速判断各模块是否同时跑通。

## 接线口径

### 主 I2C
 D4(GPIO5) -> MPU6050 SDA + MAX30102 SDA + DRV2605L SDA
 D5(GPIO6) -> MPU6050 SCL + MAX30102 SCL + DRV2605L SCL

### 副 I2C

 板载状态灯 GPIO21：用于阶段报码与运行心跳，无需外接
 新增地址级 I2C 诊断输出：串口会直接打印 `0x57(MAX30102)`、`0x68/0x69(MPU6050)`、`0x5A(DRV2605L)` 是否在线，以及 MAX30102 最近一次错误字符串，便于快速区分缺电、接线错误和总线异常。
- 基于独立探针确认用户更换的新 IMU 实际为 `MPU6500 (WHO_AM_I=0x70)`，整机环境已同步放宽 IMU 识别条件，兼容 `MPU6050/MPU6500/MPU9250/MPU9255` 常见器件族，避免整机版误报 `imu=MISS`。
- RGB 启动阶段新增 `R -> G -> B` 单色自检，每色保持约 700ms；若日志显示进入 `rgb-self-test B` 但实物蓝色仍不亮，应优先检查 D10(GPIO9)、蓝色支路限流电阻、LED 极性和共阴极接法。
- 修复了一处整机状态行 `Serial.printf` 参数错位问题。该问题会在 `setup-done` 之后、首次运行期状态打印时触发 Guru Meditation 崩溃，表现为系统看似启动成功、加热使能后不久自动重启。

### RGB 流水灯
- D8(GPIO7) -> RGB 红色阳极（串联限流电阻）
- D9(GPIO8) -> RGB 绿色阳极（串联限流电阻）
- D10(GPIO9) -> RGB 蓝色阳极（串联限流电阻）
- RGB 共阴极 -> GND

## 热反馈安全边界
- 本工程中 D1/A1(GPIO2) 只输出 80% 占空比 PWM 控制信号。
- 该信号必须接逻辑级 N-MOSFET Gate。
- 不支持也不建议把加热片直接接到 GPIO 上由单片机引脚供电。

推荐接法：
- D1/A1(GPIO2) -> 100Ω 到 220Ω -> MOSFET Gate
- Gate -> 100kΩ 下拉到 GND
- 加热片负极 -> MOSFET Drain
- MOSFET Source -> GND
- 加热片正极 -> 其额定外部电源正极
- XIAO GND 与加热片电源 GND 共地

## 串口输出口径
运行后会持续输出类似：

`[smoke] up=... | imu=... | ppg=... | pressure=... | motor=... | heater=PWM80 ...`

用于一次性判断：
- IMU 是否读到 accel/gyro/temp
- PPG 是否读到 red/ir 与 bpm/beat/contact
- 压力模块是否读到 raw/level
- DRV2605L 是否规律开关震动
- 热反馈控制脚是否已经固定输出 80% PWM
- RGB 是否按 R -> G -> B 节律循环流水

启动阶段还会先输出：

`[smoke][boot] serial-ready`

`[smoke][boot] init-mpu-start / init-mpu-ok|miss`

`[smoke][boot] init-ppg-start / init-ppg-ok|miss err=...`

`[smoke][boot] heater-enabled duty=80% gpio=...`

若现场出现“流水灯只跑一轮、串口无输出”，优先观察这些 boot 行能否打印出来，以区分：
- USB CDC 未附着
- MAX30102 或主 I2C 使总线卡住
- 加热负载过早拉起造成上电不稳

## 建议的烧录与观察方式
1. 烧录 `xiao_esp32s3_full_smoke_test`
2. 打开 115200 串口监视器
3. 先看启动阶段 `init` 行是否出现 `OK/MISS`
4. 再看运行期 `smoke` 行是否持续刷新
5. 同时观察：
   - 手持板子时 IMU 数据是否变化
   - 遮挡或贴合 MAX30102 时 IR/Red 是否变化
   - 按压压力模块时 level 是否变化
   - LRA 是否按固定节律开关震动

## 待确认事项

- 如果后续要把热反馈变成长期功能，应补温度采样或限温保护，不建议长期开环输出。
