## 主要变更
- 在呼吸校准管理器中增加单拍式 respBeatMarkerValue，并通过协议打包到 resp_debug / calibration_status
- 新增 passive_ppg_manager，复用胸口 PPG 显示链和心率估计参数，在被动监测态批量输出胸口 PPG 曲线与 beat marker
- 整机主循环接入 passivePpgManagerBegin / Tick / Consume，并通过 BLE 发布 passive_ppg_batch
- 小程序运行时新增呼吸跳点、胸口 PPG 曲线、胸口 beat marker 缓存与持久化
- 修正 device_state 高频覆盖引导文案导致的校准态吸呼提示闪烁
- 首页操作区改为两列加整行按钮，避免“删除所有数据缓存”按钮撑宽后需要横向滑动
- 日分析页新增最近 1 分钟呼吸曲线、胸口 PPG 曲线，以及“生成报告”按钮
- 整体分析页新增“生成详尽报告”按钮与结果区
- 主动报告页增加最近一条记录兜底，降低 id 不匹配导致空白的概率
- 调试页把呼吸跳点与呼吸曲线叠加绘制，便于观察呼吸检测触发点

## 实现思路
- 先补真实数据源，再补运行时缓存，最后补页面展示与报告触发，避免前端先做空壳
- 胸口被动 PPG 继续沿用现有 MAX30102 胸口调试口径，保持与独立验证环境一致
- 报告生成优先复用现有 health_insight 云函数，仅通过 prompt 区分“简要日分析”和“详尽综合报告”两类场景
- 对主动报告缺口不引入新数据结构，先用最近记录兜底，减少已有页面跳转失败时的空白感
