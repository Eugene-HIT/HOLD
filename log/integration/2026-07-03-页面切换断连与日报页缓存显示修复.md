# 2026-07-03 页面切换断连与日报页缓存显示修复

## 任务名称
修复进入模块再退出后 BLE 断连感知问题，并补齐呼吸/当天心率报告页的最近 1 分钟缓存展示入口

## 修改文件
- src/integration/passive_ppg_manager.cpp
- web/utils/hold-ble-runtime.js
- web/pages/daily-analysis/index.js

## 主要变更
- 胸口被动 PPG 批量包的 sampleIntervalMs 改为 project_config::kSensorPollIntervalMs，与独立 chest VOFA 工程口径一致
- 小程序运行时为 BLE 意外断开增加自动重连逻辑，避免用户进入模块页再返回时链路中断后停留在断连状态
- 胸口 PPG 缓存上限从 600 点改为 6000 点，对齐 10ms 采样下约 1 分钟缓存需求
- 新增胸口 PPG 专用 appendWavePointsWithCap，避免旧的 240 点调试窗口截断 1 分钟缓存
- 日分析页在尚未形成 dailyAnalyses 归档时，改为直接使用最近被动窗口与实时缓存构造 fallback day，不再因为 activeDay 为空而把波形面板和“生成报告”按钮整体隐藏
- 日级对象现在会保留 generatedReport / generatedReportUpdatedAt 字段，避免后续扩展时丢失页面态文本入口

## 一致性确认
已对比整机被动胸口 PPG 与独立 chest 工程的关键参数，当前以下口径一致：
- 显示去直流系数 kChestDisplayDcAlpha = 0.18f
- 显示轻平滑系数 kChestDisplaySignalAlpha = 0.22f
- 显示增益 kChestFilteredDisplayGain = 12.0f
- HeartRateEstimator profile:
  - presenceIrMeanThreshold = 1200
  - presenceRedMeanThreshold = 0
  - dcAlpha = 0.08f
  - amplitudeMin = 3.0f
  - amplitudeMax = 900.0f
  - signalAlpha = 0.18f
  - beatIntervalMinMs = 360
  - beatIntervalMaxMs = 2400
  - beatStaleTimeoutMs = 4500
  - contactLossResetMs = 3000
  - usePeakTroughDetector = true
- 采样节拍现已统一为 project_config::kSensorPollIntervalMs = 10ms
