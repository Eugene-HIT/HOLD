# 2026-07-05 主动报告已完整但仍显示未归档修复

## 任务名称
修复指部 PPG 详情页在已经拿到完整 60 秒实时累计记录后，仍显示“没有归档完成”并沿用未归档文案的问题

## 修改文件
- web/pages/active-report/index.js
- web/pages/active-report/index.wxml

## 主要变更
- 详情页新增 canGenerateReport 状态，改为按 archiveReady 判断是否已经具备报告生成条件
- 点击“生成这次报告”时，若当前只有 latestActiveWindow/fallback 视图但已经满足 archiveReady，则主动调用 ensureActiveMeasurementFromLatestWindow() 先补成正式主动记录，再发起报告生成
- 模型分析区域文案从“是否已有 stored report”改为“是否可以生成报告”驱动，避免已经完整缓存 60 秒记录时仍显示“未归档”

## 本次判断与结论
截图表明：
1. 页面已经显示“完整实时累计 1500 点、窗口分片 1/1、当前实时累计约 60 秒”
2. 但模型分析区域仍显示“当前还没有归档完成的 1 分钟主动检测报告”

这说明问题不在数据本身，而在详情页判断条件：
- 之前只把 activeMeasurements 中已存在正式记录视为“已归档”
- 对 latestActiveWindow 构造出的 fallback 记录，即使 archiveReady=true，也仍按未归档处理

修复后：
- 只要 archiveReady=true，就允许走正式报告生成路径
- UI 文案也同步按 canGenerateReport 切换，不再继续误导成“未归档”
