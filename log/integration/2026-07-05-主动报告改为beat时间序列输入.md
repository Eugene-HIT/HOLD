# 2026-07-05 主动报告改为beat时间序列输入

## 任务名称
按用户要求将指部主动报告的模型输入从整段波形改为 beat 时间点和 1 分钟总 beat 数，便于模型直接按节律时间序列判断 HRV

## 修改文件
- web/utils/hold-ble-runtime.js

## 主要变更
- 新增 beat 时间轴构造逻辑：优先使用 beat_ts_ms，若没有完整时间戳则从 beat marker 序列按整段时长推导相对时间点
- 新增 RR 间期序列构造逻辑，用相邻 beat 时间点之差得到毫秒间期
- 主动报告 prompt 不再向模型发送波形数组与跳点数组
- 主动报告 prompt 改为只发送：1 分钟总 beat 数、beat 时间点（相对开始毫秒）、RR 间期毫秒序列，以及必要的基础元信息

## 本次判断与结论
用户要求模型不再吃整段波形，只根据每个 beat 的时间和总 beat 数判断 HRV。本次已按该要求收敛输入面。

这样做的直接好处：
1. prompt 体积明显缩小
2. 模型输入更贴近 HRV 所需的节律时间序列，而不是波形形态
3. 后续若云端仍返回空结果，问题基本可以进一步收敛到云函数调用或上游模型响应格式，而不是输入数据过长
