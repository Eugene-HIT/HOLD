# 2026-07-05 呼吸校准改为主轴选择

## 任务名称
移除原先约 60 秒的呼吸校准阶段，改为只做主轴选择，呼吸检测参数继续使用默认值。

## 修改文件
- src/integration/resp_calibration_manager.cpp
- src/integration/device_state_machine.cpp

## 主要变更
- 删除原先 `10s 静止 + 30s 吸呼 + 21s 深吸呼` 的固定校准流程
- 新增 `kAxisSelectionSettleMs = 1200`，校准阶段只保留主轴选择与短暂稳定时间
- 主轴一旦锁定并经过短暂稳定时间，就直接触发 `completedEventPending`
- 不再生成个体化校准参数；呼吸检测继续使用当前默认阈值与默认滤波参数
- 状态机进入校准态时的提示文案从 `inhale 2s` 改为 `select main axis`

## 本次判断与结论
- 用户要求已明确收敛为：保留整机现有入口和后续流程，但移除原先 60 秒校准，只保留主轴选择
- 当前工程中的 60 秒校准完全由 `resp_calibration_manager.cpp` 中的时间分段控制，因此只需收缩该模块即可，不需要重写小程序或整体状态机
- 由于用户明确接受“参数直接用默认值”，本次不再尝试保留或生成个体化校准参数
