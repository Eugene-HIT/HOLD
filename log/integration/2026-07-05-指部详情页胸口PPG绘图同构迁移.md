# 2026-07-05 指部详情页胸口PPG绘图同构迁移

## 任务名称
将指部 PPG 详情页的波形绘图实现改为与胸口 PPG 页面同构，仅保留“主动 60 秒检测开始后才触发”这一处门控差异。

## 修改文件
- web/pages/active-report/index.js
- web/pages/active-report/index.wxml
- web/pages/active-report/index.wxss

## 主要变更
- 指部详情页新增与胸口页同构的绘图刷新链：`scheduleStateFlush -> scheduleChartDraw -> drawCharts -> drawWaveChart`
- 指部详情页绘图抽样逻辑改为直接复用胸口页的 `sampleSeriesForDisplay` 与 `buildSlidingWindowSeries`
- 指部详情页 canvas 标识改为 `chestPpgCanvas`，绘图调用形状改为与胸口页一致的 `drawWaveChart('chestPpgCanvas', ..., ..., { lineColor: '#1A1A1A', markerColor: '#FF2A8B' })`
- 页面模板中的图表说明文案改为与胸口页同构的 `chart-meta` 结构
- 显示/绘图门控收敛为：只有本页已经见过本轮 `FINGER_PPG_ACTIVE_TEST` 开始后，才显示该波形面板并开始调度绘图

## 实现说明
- 本次不再保留上一版把绘图面板额外包成指部页私有逻辑的做法，而是尽量贴近胸口页当前在跑的代码形状
- 由于详情页的数据源并不是 `activeDay.chestPpgWavePoints`，这里只保留数据输入差异，仍从当前主动记录的 `fullPpgWavePoints/fullPpgBeatMarkerPoints` 取值
- 按用户要求，不在页面初始空态直接触发绘图，必须先进入一次 60 秒主动检测状态
