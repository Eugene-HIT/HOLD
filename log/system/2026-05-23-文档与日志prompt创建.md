# 2026-05-23 文档与日志 Prompt 创建

## 任务名称
创建面向 plan agent 和 code agent 的统一文档 / log 生成 prompt

## 修改文件
- .github/prompts/create-dev-doc-and-log.prompt.md

## 主要变更
- 新增一个工作区级 prompt，用于统一生成开发前文档、开发后总结和各类 log 记录
- 明确要求生成前先检查已有文档、README、开发指南和历史 log，必要时联动更新
- 明确要求 log 应放入合理的子目录中，必要时主动创建新目录
- 明确要求在需求不确定时先与用户沟通，禁止随意选择分类或结论
- 统一规定文档结构应包含头部基本信息、目录、基本介绍、正文主体、待确认事项、验证结果和下一步建议
- 兼容开发前要求文档与开发后总结/log 两类场景

## 实现思路
- 将“生成文档”和“生成 log”统一抽象为可复用的工程文档工作流
- 把目录管理、历史文档联动、自查补全和不确定项沟通作为硬约束写入 prompt
- 让 plan agent 和 code agent 后续都可复用同一套文档输出规范
