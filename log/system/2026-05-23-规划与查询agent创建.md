# 2026-05-23 规划与查询 Agent 创建

## 任务名称
创建规划与查询专用 custom agent

## 修改文件
- .github/agents/planning-research.agent.md

## 主要变更
- 新增一个工作区级 custom agent，用于需求澄清、资料查询、方案规划和开发要求文档编写
- 明确该 agent 应优先查询官方资料、GitHub 和社区来源，并输出有依据的结论
- 明确要求该 agent 在任务过程中持续与用户交流，确认目标与边界，避免拍脑袋规划
- 明确要求开发要求文档应包含创建时间、最后更新时间、输入、输出、约束、依赖、模块划分、验收标准、风险与待确认事项、参考资料来源等内容
- 明确禁止走最小实现捷径，并要求 agent 经常自查文档与已有日志、说明的一致性

## 实现思路
- 将“规划、查询、文档输出”从偏实现型 agent 中拆分为独立角色
- 强化资料来源可靠性和与用户持续沟通两项能力
- 通过标准工作流程与质量标准约束结果质量，避免看似完整但缺乏依据的规划

## 待确认事项

- 是否需要为该 agent 增加与 engineering-research skill 对应的 references 模板
