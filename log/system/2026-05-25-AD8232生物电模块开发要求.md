# 2026-05-25 AD8232 生物电模块开发要求

## 本次变更
- 新增 AD8232 心电生物电模块的开发前要求文档
- 明确今晚目标为 AD8232 `OUTPUT` 模拟量最小读取，不扩展到临床判读
- 明确三电极模式下 RA、LA、RL 的建议角色与贴法
- 明确 `LO+` / `LO-` 仅作为可选导联状态输入，`SDN` 必须保持启用状态

## 已确认结论
- AD8232 是单导联 ECG / biopotential 前端，主输出为模拟量 `OUTPUT`
- XIAO ESP32-S3 可使用 A1 / D1 / GPIO2 作为首选 ADC 读取脚
- `LO+` 与 `LO-` 可选接入数字脚用于导联脱落检测，建议占用 D2 / GPIO3 与 D3 / GPIO4
- `SDN` 低电平会进入关断，首轮建议直接固定接 3V3
- 结合项目背景，AD8232 后续最有价值的算法方向是 R 峰、BPM、R-R 间期和 HRV，而不是单独做焦虑诊断
