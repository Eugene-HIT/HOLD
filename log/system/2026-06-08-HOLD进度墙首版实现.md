- 技术栈采用 Next.js App Router + Supabase
- 前端未引入额外 UI 框架，保持依赖轻量
- 时间轴未使用重型甘特图库，改为自定义轻量时间轴，避免继续扩大依赖与复杂度
- 图片上传走 Supabase Storage，桶名为 record-images
- 成员管理采用“白名单邮箱 + 首次登录自动建档”模式，避免额外验证码服务
