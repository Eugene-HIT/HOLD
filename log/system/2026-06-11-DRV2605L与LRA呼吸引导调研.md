# 2026-06-11 DRV2605L 与 LRA 呼吸引导调研

## 任务名称
调查 DRV2605L 驱动 LRA 是否适合本项目的呼吸节律反馈，并判断应优先使用内置效果库还是实时波形控制。

## 调研目标
- 确认 DRV2605L 是否原生支持 LRA
- 确认是否具备足够强的震动输出能力与相关限制
- 判断“吸气强到弱、呼气强到弱”的节律是否适合用内置效果库实现
- 给出后续独立验证环境的推荐控制路线

## 关键信息来源
- TI 官方产品页：DRV2605L supports ERM/LRA, 2V to 5.2V, waveform library, auto-resonance tracking, RTP mode
- TI 官方数据手册 HTML：确认 Smart-Loop、LRA auto-resonance、auto calibration、RTP、ROM waveform playback、rated voltage、overdrive clamp、closed-loop/open-loop 等能力
- Adafruit DRV2605L Breakout 指南：确认 Arduino/ESP32 侧典型接法、库使用方式、内置效果序列与实时模式示例
- Adafruit_DRV2605_Library：确认常用 API，包括 begin、useLRA、selectLibrary、setWaveform、go、setMode、setRealtimeValue

## 已确认结论
1. DRV2605L 原生支持 LRA，不是勉强兼容。
2. 对 LRA 而言，芯片的优势不只是“能震”，而是有自动谐振跟踪、自动校准、自动过驱和制动，这些比普通开关驱动更适合做可重复的节律反馈。
3. 你要的“吸气强到弱、呼气强到弱”可以实现，但不建议主要依赖 ROM 内置效果库硬拼。
4. 内置效果库更适合做两件事：
- 快速试听不同触感风格
- 组合少量短提示或状态提醒
5. 若目标是连续、可控、可调参的呼吸引导节律，主路线应为：
- LRA 模式
- 自动校准
- RTP 实时播放
- 由固件输出自定义幅值包络
6. 震动“更强”不等于把数值一直拉满。实际强度主要受以下因素共同决定：
- LRA 本体型号与额定电压
- 供电电压与瞬时供电能力
- Rated Voltage / Overdrive Clamp 参数是否正确
- 是否完成自动校准
- 佩戴位置与耦合方式
- 波形包络是否匹配 LRA 共振区工作特性

## 方案判断

### 方案 A：只用内置效果库
优点：
- 上手快
- 库已经封装好
- 适合先试听手感

缺点：
- 适合离散效果，不适合长时间连续呼吸节律
- “强到弱”的包络只能近似拼接，节律连续性有限
- 不利于后续把反馈强度与检测结果联动

结论：
- 可作为第一天的试听/验机方案
- 不应作为最终呼吸引导主方案

### 方案 B：LRA + RTP 实时幅值控制
优点：
- 可以直接生成吸气包络和呼气包络
- 便于把节拍、时长、强弱、暂停段全部参数化
- 后续能和 IMU / PPG 状态机联动

缺点：
- 需要自己管理时序和幅值曲线
- 需要先做一次 LRA 参数校准和强度摸底

结论：
- 这是本项目呼吸引导反馈的推荐主路线

## 对本项目的直接建议
1. 先做一个独立验证环境，只做 DRV2605L + LRA，不混入 IMU/PPG 逻辑。
2. 第一阶段同时保留两种测试模式：
- ROM 效果遍历模式
- RTP 呼吸包络模式
3. RTP 模式先做最小三种包络：
- 吸气：高幅值起步，随后缓降到低幅值
- 呼气：高幅值起步，随后缓降到低幅值
- 间隔：完全停止
4. 参数先暴露为串口可调：
- inhale_ms
- exhale_ms
- pause_ms
- max_level
- min_level
- ramp_shape
5. 先不要追求“最大震感”，先确认三件事：
- 是否稳定出振
- 是否佩戴后能明显区分吸气段与呼气段
- 连续工作时是否发热或失真

## 风险与待确认事项
- 目前尚未根据你手里 LRA 的具体型号核对额定电压、共振频率和推荐驱动条件。
- 若模块是第三方 DRV2605L 板，板上是否已做电平转换、上拉、电源滤波，需要看实物资料。
- 若追求非常强的体感，最终瓶颈可能在 LRA 本体和佩戴机械结构，而不是 DRV2605L 寄存器设置。
- 目前尚未输出本项目专用接线表和独立 env，需在下一步单独落地。

## 下一步建议
1. 创建独立 env，例如 drv2605l_xiao_esp32s3_lra_probe
2. 接入 Adafruit_DRV2605 库，先完成 I2C 探测和 LRA 模式初始化
3. 做 ROM 效果扫描，找出 3 到 5 个最接近目标体感的参考效果
4. 再切到 RTP，做真正的吸气/呼气包络
5. 最后再考虑与 IMU/PPG 的呼吸状态机对接
