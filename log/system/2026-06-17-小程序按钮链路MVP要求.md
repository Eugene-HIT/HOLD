## 核心收敛结果
1. 今日目标必须收敛为“按钮事件模拟硬件上报”，不能直接写成呼吸或心率链路。
2. 板载 Boot 键可作为临时按钮，但必须标注为 GPIO0 启动绑带脚，仅用于测试，不作为最终产品输入方案。
3. 云端今日必须同时打通数据库、云存储和大模型代理，不允许只做 BLE + 页面显示。
4. 推荐采用单云函数 link_test_ingest，把按钮事件入库、存储留痕和 LLM 代理一次做完。

## 关键验收定义
只有以下 4 项全部成立，今天才算闭环完成：
1. 按按钮后小程序收到 BLE 事件。
2. 页面显示次数增加。
3. 云数据库有新记录，云存储有新 JSON 留痕。
4. 小程序显示出一条来自云函数代理的大模型返回文本。
