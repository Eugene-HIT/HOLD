# MPU6050 呼吸串口采集脚本与数据口径

## 头部信息

- 相关模块：MPU6050 呼吸实验 / 串口采集 / 算法数据导出

## 修改文件
- tools/serial/capture_mpu6050_respiration.py

## 主要变更
- 新增 Python 串口采集脚本，默认读取 COM9 / 115200。
- 脚本会同时输出：
  - 原始串口日志 raw_serial.log
  - 运行期 VOFA 带表头 CSV vofa_runtime.csv
  - 文本事件日志 events.log
  - 采集摘要 summary.json

## 数据口径结论
- 当前 mpu6050_xiao_esp32s3_respiration 运行期 VOFA 输出为 17 列数值帧。
- 这些列覆盖了呼吸载波、基线、去趋势、一级低通、斜率、幅度门限、上次峰谷值、动态加速度范数、角速度范数、运动等级、拒绝原因、峰谷状态和已接受周期数。
- 当前运行期 VOFA 帧不包含 acc_raw/gyro_raw 六轴原始值。
- 但校准/文本模式下源码仍会打印 acc_raw 与 gyro_raw 文本行。

## 实现思路
- 先不修改固件口径，优先保证当前串口数据可稳定落盘并附带列名，便于算法同学直接读取。
- 对于运行期数值帧，按固定 17 列识别并整理为 CSV。
- 对于其余文本输出，完整保留到 raw_serial.log 和 events.log，避免丢失校准与状态上下文。

## 验证结果
- 新增脚本已通过 python -m py_compile 语法校验。

## 待确认事项
- 若算法同学明确要求运行期逐样本 acc_raw/gyro_raw 六轴原始值，则需要再修改固件 VOFA 口径或新增独立 raw 导出 env。

## 下一步建议
- 先使用现有脚本采一段稳定呼吸数据给算法同学做首轮观察。
- 若对方确认现有 17 列不足，再补固件侧 raw 六轴输出。
