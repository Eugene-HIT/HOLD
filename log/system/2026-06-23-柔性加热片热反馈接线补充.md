## 接线结论
推荐采用“外部供电 + 逻辑级 N-MOSFET 低边开关”方案：
- 加热片正极 -> 加热片额定电源正极
- 加热片负极 -> MOSFET Drain
- MOSFET Source -> GND
- XIAO D11(GPIO42) -> 100Ω 到 220Ω 电阻 -> MOSFET Gate
- Gate -> 100kΩ 下拉到 GND
- XIAO GND 与加热片电源 GND 共地

## 这样做的原因
- 加热片通常电流明显大于 GPIO 可承受能力，不能直接由单片机引脚供电
- 当前工程已有多组独立实验占线：
  - IMU：D4 / D5
  - PPG：D2 / D3
  - LRA：D6 / D7
- 因此本轮建议把 D11(GPIO42) 预留给单路热反馈控制

## 风险与待确认事项
- 目前尚未拿到具体加热片型号，因此无法准确给出额定电压、电流、功率和连续工作时长
- 若后续需要贴肤使用，建议尽快补充温度传感器或限温器件，不建议长期无闭环直驱
- 若加热片不是 3.7V/5V 规格，需要另外补升压或稳压模块

## 下一步建议
1. 确认你手里的柔性加热片额定电压和功率
2. 选定逻辑级 N-MOSFET 型号，例如 AO3400、IRLML6344 或同类
3. 若后续要做“温热渐强/渐弱”，再单独补一个独立热反馈实验环境
