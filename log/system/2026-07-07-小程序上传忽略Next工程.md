# 2026-07-07 小程序上传忽略 Next 工程

## 任务名称
修复微信开发者工具上传小程序时扫描到 `web/hold-progress-wall/.next` 构建产物，导致上传阶段报 `Cannot read properties of undefined (reading 'length')` 的问题。

## 修改文件
- web/project.config.json

## 主要变更
- 在微信小程序工程配置的 `packOptions.ignore` 中新增目录忽略规则
- 排除 `hold-progress-wall` 目录，避免将 Next.js/Turbopack 产物纳入小程序上传包
- 同时排除 `miniapp_ble_link_test` 目录，避免无关测试目录被扫描进正式小程序上传流程

## 本次判断与结论
- 报错文件位于 `web/hold-progress-wall/.next/build/...js`，不属于小程序运行时需要上传的资源
- 当前小程序工程根目录是 `web/`，而 `hold-progress-wall` 是并存的另一个 Web/Next 工程
- 因此问题不是业务小程序源码本身出错，而是上传打包范围过宽

## 验证结果
- `web/project.config.json` JSON 解析通过
- VS Code 对 `web/project.config.json` 未报错误

## 待确认事项
