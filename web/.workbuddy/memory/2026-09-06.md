**改动范围**

- `app.json`：调整 `pages` 顺序，新增底部 `tabBar`（首页 / 记录 / 分析），保留米白暖色配色。
- `app.wxss`：建立设计 token（卡片、按钮、文本层级、状态点），所有页面复用 `.app-card / .app-section-title / .app-button` 等全局类。
- 新增 `pages/debug/`（4 个文件）：独立设备调试台，迁移并增强原 `pages/index` 的能力：扫描连接 / 断开 / 下发呼吸引导 / 清空调试窗口（轻）/ 删除全部数据缓存（二次确认重）/ 实时指标 / 双波形 / 调试日志（展开/复制）/ 原始报文（复制）/ 主动检测归档状态（从 active-report 迁过来的调试字段）/ 运行环境（基础库、机型、本地存储）。

- `pages/active-history/`：作为「记录」tab 页；改用统一 app-card 风格；修正了内嵌 wx:for 的 `wx:for-item` bug（原写用 `item` 覆盖外层）；新增 `index.json`（"检测记录"）。
- `pages/overall-analysis/`：作为「分析」tab 页；统一卡片样式；新增 `index.json`（"整体分析"）。
- `pages/active-report/`：删除 `pageBuildTag` 与所有 `runtimeDebugInfo` 调试字段（这些字段已迁移到 debug 页的「主动检测归档状态」面板）；wxml 改为统一卡片风格。

## 分析页整体趋势：一体卡重构 + 数据链路修复

- UI：原「状态卡 + 3 张独立板块卡」合并为**一张 trend-card**：当前状态摘要 → 建议（`#f6f2e8` 内嵌块，带「建议」小标签）→ 呼吸报告 → 心率报告（细分隔线 + 色点）→ 底部刷新分析按钮 + 更新时间；顶部 topbar 的「更新于」移除（与卡内底部重复）。板块只保留 resp/heart 两个，去掉 overall 总结板块（与摘要重复）。
- 数据修复（runtime `parseInsightReply` 两个真实 bug）：
  1. 模型返回常被 ```json 围栏包裹或带前后解释文字 → `JSON.parse` 失败 → 整段塞进 summary、板块全退化为兜底。新增 `extractInsightJsonText`：剥围栏 + 提取最外层 `{}`。
  2. 原逻辑只要模型 sections 是非空数组就整体替换 fallback → 模型少返回 key 时本地兜底文案也丢。新增 `normalizeInsightJson`：按 key 把模型板块合并到 fallback 上，缺 key 保留本地兜底。
- 已用 node 单测验证三种输入（围栏 JSON / 前后带文字的 JSON / 纯文本）行为正确。
